# Getting help

- **Questions, ideas, showing what you built:** [Discussions](https://github.com/Mohamedattiadev/igrek/discussions).
- **Something does not work:** in Igrek, help button (bottom right), **Report a problem**. It prepares an
  issue with your version, system and the last lines of the log, private details taken out, and opens it
  on GitHub only after you have read it. You can also [open an issue](https://github.com/Mohamedattiadev/igrek/issues/new/choose) by hand.
- **Security problems:** privately, as [SECURITY.md](SECURITY.md) explains. Never in a public issue.
- **Docs:** [mohamedattiadev.github.io/igrek](https://mohamedattiadev.github.io/igrek/).

Igrek is made by one person. Answers usually come within a few days.
