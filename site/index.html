What leaves your computer

The part people ask about first.

Your code goes to Claude or Codex the same way it does without Igrek, through your own subscription. Nothing is sent to us: there is no account, no telemetry and no server of ours. Settings lists every address Igrek connects to.

  • No API keys: it uses the Claude and Codex logins you have
  • Pushing, deploying and publishing wait for your OK
  • If a file asks AI tools not to help, Igrek shows you the line and you decide

Questions

Is it free?

Yes, for people and companies. It runs on your own Claude or Codex plan, and anything that calls a model is marked so you can see what uses your limit.

Does my code leave my computer?

Only to the AI you already use, the same way Claude Code and Codex send it. Igrek adds no telemetry and has no server. Private details are replaced by placeholders first.

Why does the first start download something?

Igrek's server runs on Bun. To keep the installer small, the app downloads Bun's official release once (about 35 MB), checks it against Bun's published checksum and keeps it.

Is it open source?

The source is open to read, but it is not open source: the Igrek Use License lets anyone use it for free, while selling it, redistributing it or offering it as a service needs written permission.
