Install

You need Git and Claude Code (run claude once to log in). The script installs Bun when it is missing.

Linux and macOS

curl -fsSL https://raw.githubusercontent.com/Mohamedattiadev/igrek/main/scripts/install.sh | sh

Windows (PowerShell)

irm https://raw.githubusercontent.com/Mohamedattiadev/igrek/main/scripts/install.ps1 | iex

On Windows install Git for Windows first: Claude Code uses the bash it brings. The built-in terminal does not work on Windows yet; chats do.

With Docker

git clone https://github.com/Mohamedattiadev/igrek.git && cd igrek
docker compose up -d

Then open http://localhost:7777. Settings, Igrek as an app, gives it a window of its own.

First run

Pick your language, then your project folders: one project, or a folder that holds several. Igrek shows only the folders you add; folders where Claude already worked are one click away.

Chats

The box holds what every message needs: text, images, ready-made prompts and experts. Approvals, model and detail sit behind Settings. Above the box: the agent's plan, your own to-do list for the chat, and the files the chat changed, each with its diff and a one-click undo. The header says what the last turn took from your limit. Everything that calls a model carries a small gauge mark.

Why?

Every changed file has a Why? button: the request that led to the change, the plan step it belonged to, and the expert asked in the same turn. It is read from the chat itself; nothing is guessed.

Experts

Igrek ships about thirty experts, from security and databases to product and finance. Each masters its field (standards, numbers, how it decides). Mention one with @ in a chat, ask all of them about a project, or turn on Expert review of sensitive changes in Settings: when a turn touches login, payment or database code, the matching expert reads the diff. Each review is one model call, so it is off by default.

Packages

Experts, Packages: open Igrek's reviewed catalog, a file, or an https address. You always see what a package holds before anything is saved, and you pick the parts. Experts from a package start read-only and off the web and never replace yours; flows that run shell commands are refused; flows are kept in Igrek's folder, not your repository. Make a package from your own experts to share them.

Teams

An optional hub, on a server you run, shares the projects you choose, end to end encrypted. Everyone uses their own AI account; accounts are never shared. See the README for setting up a hub.

Moving to another computer

Settings, Move to another computer: one file locked with a password holds everything Igrek keeps. Open it in Igrek on the other computer and restart. AI logins are not in it; log in again there.

Privacy

Everything runs on your computer. Igrek has no telemetry and calls no paid API; every address it opens on the internet is listed in Settings. Security problems: see SECURITY.md.

Update and remove

Run the install command again to update. To remove Igrek, delete its folder (~/.local/share/igrek-app, or %LOCALAPPDATA%\igrek-app on Windows), the launcher igrek, and its data in ~/.igrek.
