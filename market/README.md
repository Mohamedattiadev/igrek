# Igrek packages

Packages of experts and team flows, opened in Igrek under Experts > Packages. `index.json` is the
catalog Igrek shows; a package is added to it only after review (open an issue with its address).

Rules every Igrek applies when it opens a package, from here or from anywhere else:

- what the package holds is shown first, and only the parts you pick are saved;
- its experts start read-only and without the web, and never replace an expert you already have;
- flows that run shell commands are refused;
- its flows are kept in Igrek's own folder, never in your project's repository.
