# Contributing to Igrek

Igrek is source-available under the Igrek Use License (see `LICENSE`): you may use it, read it and
report problems, but not copy, redistribute or republish it.

## Issues are welcome

Bugs, ideas and questions go to GitHub Issues. Please never paste keys, passwords or private code;
security problems go privately (see `SECURITY.md`).

## Pull requests

A pull request can only be accepted when you agree to this, by writing the sentence below in the pull
request's description:

> I wrote this change myself (or have the right to give it), and I give Mohamed Attia all rights in it,
> including the right to use, change, license and sell it, with no payment and no conditions.

Without that sentence a pull request is closed without being read. A fork made only to send a pull
request is allowed by the license; keep it until the pull request is closed, and do not publish or
distribute it in any other way.

The rules for the code itself (checks that must pass, texts in every language, no emoji, everything
free) are in `AGENTS.md` and apply to people too.

# Igrek'e katkı (Türkçe)

Igrek kaynağı açık ama açık kaynak değil (`LICENSE`): kullanabilir, okuyabilir, sorun bildirebilirsin;
kopyalayıp dağıtamaz ya da yeniden yayınlayamazsın.

- **Sorun bildirmek serbest:** GitHub Issues. Anahtar, şifre ya da özel kod yapıştırma; güvenlik açıkları
  gizlice bildirilir (`SECURITY.md`).
- **Pull request** sadece açıklamasında yukarıdaki İngilizce cümle varsa kabul edilir (değişikliğin bütün
  hakları karşılıksız ve koşulsuz Mohamed Attia'ya geçer). Cümle yoksa okunmadan kapatılır.
- Sadece pull request göndermek için açılan fork serbesttir; başka şekilde yayınlanamaz.
